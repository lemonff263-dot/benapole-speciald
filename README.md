## 🚀 GitHub এ কোড সেভ ও পুশ করার নিয়মাবলী (How to Push to GitHub)

আপনার প্রজেক্টের সমস্ত কোড уже গিট রিপোজিটরিতে কমিট করার জন্য তৈরি। GitHub-এ আপলোড করার জন্য নিচের সহজ ধাপগুলো অনুসরণ করুন:

### ধাপ ১: GitHub এ নতুন রিপোজিটরি তৈরি করুন
1. [GitHub](https://github.com) এ লগইন করুন।
2. উপরে ডানপাশে `+` আইকনে ক্লিক করে **New repository** সিলেক্ট করুন।
3. রিপোজিটরির নাম দিন (যেমন: `benapole-sweets-app`)।
4. **Public** অথবা **Private** পছন্দ করুন।
5. "Initialize with README" তে টিক দেবেন **না** (কারণ কোড অলরেডি তৈরি আছে)।
6. **Create repository** বাটনে চাপ দিন।

### ধাপ ২: টার্মিনালে নিচের কমান্ডগুলো রান করুন
GitHub এ আপনার রিপোজিটরির যে লিংক পাবেন (যেমন: `https://github.com/your-username/benapole-sweets-app.git`), সেটি দিয়ে নিচের কমান্ডগুলো রান করুন:

```bash
# গিট রিমোট রিপোজিটরি যুক্ত করুন (আপনার গিটহাব লিংক দিন)
git remote add origin https://github.com/YOUR_USERNAME/benapole-sweets-app.git

# মেইন ব্রাঞ্চ নির্ধারণ করুন
git branch -M main

# GitHub এ সমস্ত কোড পুশ করুন
git push -u origin main
```

## 🌐 Netlify তে ফ্রি লাইভ পাবলিশ করার নিয়ম (Deploy to Netlify)

1. [Netlify.com](https://www.netlify.com/) এ গিয়ে আপনার GitHub একাউন্ট দিয়ে **Sign Up / Log In** করুন।
2. ড্যাশবোর্ডে **"Add new site"** -> **"Import an existing project"** এ ক্লিক করুন।
3. **GitHub** অপশনটি নির্বাচন করুন এবং আপনার তৈরি করা `benapole-sweets-app` রিপোজিটরিটি সিলেক্ট করুন।
4. Netlify স্বয়ংক্রিয়ভাবে `netlify.toml` ফাইল থেকে সেটিংস পড়ে নেবে:
   - **Build Command**: `npm run build`
   - **Publish directory**: `.next`
5. **"Deploy site"** বাটনে ক্লিক করুন।
6. ২ মিনিটের মধ্যে আপনার ওয়েবসাইটটি সারা বিশ্ব থেকে ভিজিট করার জন্য একটি লাইভ লিঙ্ক (`your-site.netlify.app`) পেয়ে যাবে! চাইলে আপনার নিজস্ব ডোমেইনও যুক্ত করতে পারবেন।

## 🛠️ লোকাল ডেভেলপমেন্ট (Local Development)

আপনার কম্পিউটারে প্রজেক্টটি চালাতে:

```bash
# প্যাকেজ ইন্সটল করুন
npm install

# ডেভেলপমেন্ট সার্ভার রান করুন
npm run dev
```

ব্রাউজারে [http://localhost:3000](http://localhost:3000) ওপেন করলেই ওয়েবসাইটটি দেখতে পাবেন।
